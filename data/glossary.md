# Глоссарий: русские названия = английские (Soulstone Survivors)

Источник: файлы самой игры (resources.assets), русская и английская локализации сопоставлены по внутренним ключам. Это официальные названия из игры на момент сборки (октябрь 2026), версия игры не фиксировалась. После крупного патча названия могут измениться.

Как пользоваться:
- Если пользователь называет персонажа, оружие, навык, пассивку или врага по-русски, найди английское название здесь и дальше ищи в сети только по английскому.
- Если несколько английских вариантов через «/», это разные записи с одинаковым русским названием (например, название и тег). Выбирай по контексту.
- Если названия нет в глоссарии, быстро поищи в вики по описанию, а при неудаче задай пользователю один вопрос: как это называется в английской версии.
- «Изгнание» = Banish, «Переброс» = Reroll. Слово «vanish» из запросов пользователя означает Banish.
- Руны: отдельных названий конкретных рун в данных не найдено, в глоссарии только интерфейсные термины.
